# Two excerpts from a single run of GameViewer.exe under Wine 11.17 on Arch Linux.
# Log written by a shim inside the process: it hooks GetOutlineTextMetricsW in
# qwindows.dll's import table and QString::fromWCharArray in every module.
#
# caller qwindows.dll+0x7041f = the size query, +0x7043a = the fill.
# Every other font in the session produces an agreeing QUERY/FILL pair; the pair
# immediately before each crash is the bitmap-only emoji face, where both return 0.
#
# NOTE the pointer: the FILL line's otm= and the next line's rdi= are the same
# address, which is what ties the failed call to the bad pointer Qt then uses.
